<sub><a id="principles"></a>04 &nbsp;/&nbsp; HOW I THINK</sub>

## features are easy.<br>good products are not.

Before anything ships, it has to answer five questions.

<br>

<sub>01</sub>&nbsp;&nbsp; Does this need to exist?<br>
<sub>02</sub>&nbsp;&nbsp; Does it make someone's life easier?<br>
<sub>03</sub>&nbsp;&nbsp; What happens at 10,000 users?<br>
<sub>04</sub>&nbsp;&nbsp; Can it survive its first real failure?<br>
<sub>05</sub>&nbsp;&nbsp; Does the interface feel obvious without an explanation?

<br>

<sub>No good answer? It doesn't ship yet.</sub>
